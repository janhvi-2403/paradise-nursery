# Paradise Nursery Shopping Application

## Project Overview

Paradise Nursery is an online plant shopping application that allows users to browse and purchase a variety of houseplants.

## Features

- Browse houseplants organized into different categories.
- View plant names, images, descriptions, and prices.
- Add plants to the shopping cart.
- View the total number of items in the cart.
- Increase or decrease plant quantities.
- Remove plants from the shopping cart.
- Calculate item totals and the overall cart amount.
- Navigate between the Home, Plants, and Cart pages.

## Technologies Used

- React.js
- JavaScript
- CSS
- Redux Toolkit
- React Redux
- React Router

## Project Purpose

The purpose of this project is to demonstrate frontend development skills by building an interactive e-commerce shopping application using React and Redux.
