# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a simple project that calculates the simple interest based on the principal amount, rate of interest, and time period. It is implemented using a Bash shell script.

## Formula
Simple Interest is calculated using the following formula:

**Simple Interest = (Principal × Rate × Time) / 100**

Where:
- **Principal (P):** The initial amount of money.
- **Rate (R):** The annual rate of interest in percentage.
- **Time (T):** The time period in years.

## Features
- Accepts the principal amount from the user.
- Accepts the annual rate of interest.
- Accepts the time period in years.
- Calculates and displays the simple interest.
- Beginner-friendly Bash shell script.

## How to Run
1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Give execution permission to the script:

   ```bash
   chmod +x simple-interest.sh
   ```

4. Run the script:

   ```bash
   ./simple-interest.sh
   ```

5. Enter the principal amount, rate of interest, and time period when prompted.

## Example
Suppose:
- Principal = 1000
- Rate = 5%
- Time = 2 years

Calculation:

Simple Interest = (1000 × 5 × 2) / 100 = 100

**Output:** Simple Interest = 100
